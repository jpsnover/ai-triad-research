# Risk Report Format

**Last updated:** 2026-07-27
**Author:** Risk Assessor (Orca)

Structured format the Risk Assessor uses when producing a risk report. One block per identified risk; severity is Critical/High/Medium/Low with clear rationale.

```
### [SEVERITY] Risk Title
- **Risk:** What could go wrong
- **Likelihood:** High/Medium/Low
- **Impact:** What happens if it occurs
- **Mitigation:** Specific steps to reduce risk
- **Recommendation:** Proceed / Proceed with mitigations / Block
```
