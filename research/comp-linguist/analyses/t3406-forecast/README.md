# t/3406 — anticipated_challenge forecast-accuracy metric (baseline + τ calibration)

Does a debater's opening-plan `anticipated_challenges` foresee the attacks that actually land on it?
Two metrics, per debater per debate:
- **`anticipated_challenge_hit_rate`** — of my forecast challenges, the fraction that materialized (matched a real opponent attack on me).
- **`blindside_rate`** — of the attacks that actually landed on me, the fraction I did NOT foresee.

## Method (v2, valence-aware)
An anticipated_challenge "materialized" iff it is embedding-similar (all-MiniLM-L6-v2 cosine ≥ τ) to an
**atomic opponent claim that stands in an `attacks` edge targeting one of the debater's own AN nodes** —
i.e. an attack that actually landed, not any topically-similar sentence. Computed offline from
`debates/debate-*.json` (`anticipated_challenges` in the opening-plan stage-diagnostics; opponent attacks
from `argument_network` nodes+edges). No DebateTool emission needed for the research read.

**Why v2, not v1:** v1 matched challenges against *all raw opponent sentences* → topical inflation
(hit_rate 0.83 @ τ0.5) and no valence. Restricting to atomic *attacks-that-landed* is the correct
denominator and collapses the number to a sober level; it also makes blindside_rate computable.

## τ calibration (`tau_calibrate.py`)
40-pair single-annotator golden (`tau_worksheet.txt` generated by `tau_golden_gen.py`; labels in
`tau_calibrate.py`), stratified across cosine 0.35–0.74. Precision-first (a false match inflates hit /
deflates blindside):

| τ | precision | recall |
|---|---|---|
| 0.62 | 1.00 | 0.44 |
| **0.60** | **0.82** | **0.50** |
| 0.55 | 0.75 | 0.67 |
| 0.50 | 0.61 | 0.78 |

**Calibrated τ = 0.60** (precision knee).

## Baseline result (51 debates, 145 debater-sides, τ=0.60)
- **hit_rate = 0.063** (precision-adjusted ≈ 0.05)
- **blindside_rate = 0.972**

**Verdict:** today's `anticipated_challenges` foresee only ~5–6% of the attacks that land; ~97% of
landing attacks were not specifically anticipated. Empirically near-useless as targeted foresight — reads
as generic defensive posturing. This is the **pre-improvement baseline** for t/3404 (steelman/specificity)
+ t/3405 (seed from node `steelman_vulnerability`).

## Provenance & limitations
- Class **derived** (evidence = this golden), **single-annotator**, reporting-treatment **single-draw ⚠**.
  Same status class as `formalization_accuracy` 0.778. Re-validate τ with a 2nd annotator before it gates anything.
- Cosine has ~2/40 genuine matches below 0.45 (mild undercount).
- AN-coverage-dependent (needs `attacks` edges).
- `blindside` denominator = all landing attacks, some genuinely un-anticipatable → ~97% is a ceiling, not a failing grade.
